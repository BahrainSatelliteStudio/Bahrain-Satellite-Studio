// مواصفات واجهات التطبيق — مرجع البناء (من صور التطبيق القديم Bahrain Satellite 1.0.7)

## تسلسل الشاشات عند أول تشغيل
1. نوع الجهاز: جوال 📱 / تلفاز 📺 (مرة وحدة، يُحفظ)
2. اللغة: العربية / English
3. شاشة الدخول

## 1) شاشة الدخول
- الشعار (تلفاز فيه علم البحرين) + "Welcome to Bahrain Satellite" + "PREMIUM IPTV EXPERIENCE"
- بطاقة بإطار ذهبي يلمع: اسم المستخدم، كلمة المرور (إظهار/إخفاء)، كود السيرفر (اختياري)
- زر "دخول" ذهبي كبير
- أزرار: تفعيل كود / الدعم / المتجر
- رابط "التحميلات دون إنترنت" أسفل
- خلفية كحلية غامقة بأشكال مائلة بحواف ذهبية ونقاط
- الدخول: مستخدم + كلمة مرور فقط؛ كود السيرفر يحدد السيرفر المطابق

## 2) الرئيسية (بعد الدخول) — واجهة التلفاز
- قائمة جانبية يمين بأيقونات: مباشر، الأفلام، المسلسلات، المفضلة، متابعة المشاهدة، التحميلات، البحث، تحديث، الإعدادات
- الشعار أعلى اليمين، الساعة والتاريخ أعلى المنتصف
- صفوف أفقية: "أحدث الأفلام" و"أحدث المسلسلات" ببطاقات بوستر + شارة ذهبية "جديد" + الاسم والسنة
- شريط سفلي: "الاشتراك صالح حتى: تاريخ" (يسار) + "v1.0.7 · build 8" (يمين)
- ميزات جديدة: التحميلات، تاريخ انتهاء الاشتراك

## 3) المباشر (ثلاثة أعمدة)
- يمين: التصنيفات — "الكل" بعدد القنوات، المفضلة العامة ❤️، المفضلة الرياضية ⚽، ثم التصنيفات مع الأعداد، وزر "رجوع" أسفل
- وسط: قائمة القنوات مرقّمة بشعارات وأسماء + بحث أعلى
- يسار: معاينة حية (LIVE PREVIEW) للقناة المحددة + اسمها + زر "إضافة إلى المفضلة" ☆
- التصنيف المحدد بإطار ذهبي

## 4) اختيار المفضلة (داخل المباشر)
- نافذة "اختر المفضلة": المفضلة العامة ☆ / المفضلة الرياضية ☆ + إغلاق
- قائمتان منفصلتان تظهران في عمود التصنيفات مع الأعداد

## 5) تشغيل قناة (ملء الشاشة)
- بث ملء الشاشة بخلفية سوداء
- شريط سفلي عند التحكم: شعار القناة دائري، "006 | News | Ar: Al Jazeera Mubasher"، التصنيف (الاخبار ⭐ News)، الساعة يسار
- زر "ملء الشاشة" أعلى اليمين
- الشريط يختفي تلقائيًا ويرجع مع أي تحكم

## 6) الأفلام
- شريط أعلى: زر "بحث" 🔍 بإطار ذهبي (يسار)، العنوان "الأفلام — الكل (9932)" (وسط)، تسمية "التصنيفات" (يمين)
- عمود تصنيفات يمين: الكل ★ (العدد الكلي)، أضيف حديثًا ✨، استئناف المشاهدة 0، ثم التصنيفات مع الأعداد (مثال: عربي قديم ARABIC 270، مصارعة Wwe 323، نتفلكس NETFLIX 378، انجليزي [EN] 916، [AR] English Movi... 2018 528، 2026 418، 2025 908…)، زر "رجوع ←" أسفل
- شبكة بوسترات (5 أعمدة تقريبًا على التلفاز)، تحتها اسم العمل + السنة
- التصنيف المحدد بإطار ذهبي، الخلفية كحلية غامقة

## 7) ترتيب المحتوى (داخل الأفلام)
- زر "الأحدث" بجانب البحث في الشريط العلوي يعرض الترتيب الحالي
- يفتح نافذة "ترتيب المحتوى حسب" بإطار ذهبي، اختيار واحد (راديو ذهبي):
  حسب الإضافة (الأحدث) [افتراضي] / حسب الرقم / حسب الاسم A-Z / حسب الاسم Z-A / حسب التصنيف
- ملاحظة: التسمية الصحيحة "استئناف المشاهدة" (وليس استبعد المشاهدة)

## 8) صفحة تفاصيل الفيلم (عند الدخول على فيلم)
- خلفية: صورة الفيلم الكاملة (backdrop) تملأ الشاشة مع تعتيم خفيف
- زر "رجوع ←" أعلى اليسار (مربع بإطار ذهبي)
- أعلى اليمين: اسم الفيلم والسنة بخط كبير أبيض (مثال: "0 0 Mhz 2019")، وتحته تصنيف "فيلم"
- شارة مدة الفيلم بإطار ذهبي (مثال: 01:41:46) + عدّاد المفضلة بإطار ذهبي (مثال: 0 ★)
- سطر وصف: "لا يوجد وصف متوفر لهذا الفيلم من المصدر" عند غياب القصة
- أربعة أزرار بإطار ذهبي في صف واحد (من اليمين): "تشغيل ▶" (الأكبر) / "تحميل" / "تفضيل" / "مفضلة ☆"
- ميزات جديدة سجّلتها للبناء: زر تحميل الفيلم، زر تفضيل، عدّاد المفضلة، المدة المعروضة، خلفية الفيلم كاملة

## 9) شاشة تشغيل الفيلم (ملء الشاشة)
- شريط علوي أسود: عنوان الفيلم والسنة في المنتصف (مثال "0 0 Mhz 2019")، زر رجوع ↩ أعلى اليمين
- شريط تقدم رفيع + مؤشر دائري ذهبي، الوقت الحالي يسار (مثال 00:00:05) والمدة الكلية يمين (مثال 01:41:46)
- أزرار مركزية: ترجيع مزدوج ◄◄ / إيقاف مؤقت ⏸ داخل دائرة رمادية نصف شفافة / تقديم مزدوج ►►
- شريط سفلي أسود فيه 6 أيقونات (يسار ← يمين): الوضع الليلي 🌙 (ذهبي) / المعلومات ⓘ / الصوت 🔊 / الترجمة cc / تسريع ⚡ (ذهبي) / ملء الشاشة ⛶
- الشريطان يختفيان تلقائيًا ويظهران مع أي تحكم
- بانتظار تفاصيل كل أيقونة: ما الذي تفتحه (قوائم الترجمة/الصوت/الوضع الليلي/التسريع/المعلومات)
