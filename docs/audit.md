# تقرير المراجعة والتنظيم — 18 أكتوبر 2026

## النطاق
مراجعة مصدر المشروع، اختبارات الانحدار الحالية، الصفحات العامة، وفصل المسؤوليات. لم تُعدّل البيانات أو السياسات أو البروتوكولات أو مفاتيح التوقيع أو القوالب الحالية. لم تُنفّذ إصلاحات الأمان المقترحة ضمن نقل الملفات.

## ما نُظّم
- فُصلت أقسام إدارة الزبون إلى الرئيسية والسيرفرات والهوية والقالب والتواصل والإشعارات والإصدارات والسجل والنسخ والأمان والاستوديو.
- جُمّعت مساعدات الحفظ والسجل والرفع والاستعلام في ملف مشترك دون تغيير العمليات.
- فُصل التطبيق إلى نقطة تجميع وعرض مشترك ودخول فعلي وتجريبي وإعدادات وتصفح وإعلانات وتنقل.
- فُصل الاتصال إلى إعدادات التطبيق ومزوّدي البث والتفعيل وإدارة الزبائن والبناء وفحص الهوست؛ بقيت نقاط الاستيراد القديمة صالحة.
- نُظمت ملفات عرض الرئيسية وإدارة الأكواد واستعلام مكتبة التطبيقات تحت مجالاتها.
- استُبدلت تأكيدات وجود عناصر المصفوفة في الأجزاء المنقولة بتحقق صريح، دون تغيير المسار الطبيعي.
- لم تُعدّل الملفات المولّدة أو سجل الترحيلات أو إعدادات النشر أو اللوحة المستقلة.

## نتائج خط البداية
15 حالة اختبار في 7 ملفات نجحت قبل النقل، ونجحت بعد الفصل الأول. الرئيسية والدخول فُتحا دون أخطاء تشغيل ظاهرة. هذه أدلة جزئية، وليست تغطية كاملة للصلاحيات المنشورة أو Android أو البث الحقيقي.

## قائمة منفصلة تحتاج مراجعة قبل الإصلاح
| الملاحظة | الحالة والتوصية |
|---|---|
| إنشاء التوقيع عند وجود بعض الأسرار فقط | مخاطرة مؤكدة من قراءة الشرط؛ يلزم مسار استعادة يمنع استبدال الهوية جزئيًا واختبار فشل أثناء الحفظ. |
| Debug من VPS مقابل Release من GitHub | اختلاف مؤكد في السكربت؛ لا توزيع Debug كإصدار نهائي. توحيد المسار لاحقًا لا يتضمن تبديل المفتاح. |
| واجهات البث والإشعارات العامة | لا تظهر حدود محلية لكل طلب/جهاز في المصدر؛ يجب فحص الحماية الفعلية قبل تقرير ثغرة، ثم حماية لا تكسر APK. |
| قفل التفعيل الخارجي المؤقت | لا ينسق عدة عمليات خادم؛ التفعيل المملوك يستخدم المعاملة الذرية بالفعل. مراجعة المسار الخارجي مستقلة. |
| استلام نتيجة البناء | سر مشترك مع غياب قيود محلية واضحة للأحجام والتكرار؛ اقتراح تفويض مرتبط بكل بناء ومراجعة انتقال الحالة. |
| اللوحة المستقلة | مراجعة HTTPS والجلسات وقيود الدخول وكتابة JSON وطلبات الخادم؛ تبقى دون اعتماديات. |
| صلاحيات البيانات والتخزين المنشورة | المصدر لا يثبت الإعدادات المنشورة؛ يلزم فحص فعلي واختبار حساب زبون غير مخوّل. |
| تحذيرات تقادم التحقق | موجودة؛ لم نغيّر واجهة الاستدعاء أثناء التنظيم لتجنب إدخال تغيير تشغيل إضافي. |

تنزيل نسخة التوقيع من شاشة المسؤول المحمية ميزة احتياطية موجودة، وليس دليل تسريب بذاته؛ يلزم التحقق من الصلاحيات وعدم التسجيل قبل تغييره.

## غير معتمد خارجيًا
تثبيت APK وتحديثه على Android والتلفاز، البث الفعلي من مزوّد مسموح، التشغيل على VPS فعلي، إعدادات الخدمات المنشورة، ومحاولات وصول زبون غير مالك. لا يغلق ترتيب الملفات هذه البنود.
