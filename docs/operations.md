# التشغيل والتصدير والتسليم

## قبل إصدار تطبيق زبون
1. تحقق من اسم الزبون واسم الحزمة وشعاره وإعداداته والسيرفرات المقصودة.
2. سجّل الحزمة الصحيحة في Firebase كتطبيق Android، ونزّل `google-services.json` وارفع الملف الصحيح من صفحة الإشعارات.
3. تحقق من ربط GitHub ومن وجود جميع أسرار التوقيع؛ لا تولّد مفتاحًا جديدًا لتعويض حالة جزئية قبل مراجعة النسخة الاحتياطية.
4. احتفظ بنسخة المفتاح الاحتياطية في مكان خاص وآمن؛ لا تضعها أو كلمة مرورها في المصدر أو سجل العمل.
5. استخدم مسار GitHub Actions للإصدار النهائي الموقّع؛ سكربت `scripts/build-apk-vps.sh` ينتج Debug حاليًا، للاختبار فقط.
6. ثبّت الإصدار على Android وجهاز تلفاز، واختبر الدخول والقوائم والبث والاستكمال والمفضلة والإشعارات والتحديث؛ نجاح الموقع ليس اختبارًا لهذه الأجهزة.

## تحقق الزبون والمعاينة
- افتح إعدادات الزبون بحساب مخوّل؛ عدّل قيمة قابلة للاستعادة، احفظ، وأعد فتح الصفحة للتحقق من القراءة.
- جرّب المنع بحساب زبون لا يملك التطبيق، دون منح صلاحيات جديدة بغرض الاختبار.
- بدّل قالبًا مع حفظ الأقسام؛ أعد الإعدادات الأصلية بعد الاختبار.
- تأكد من بقاء سجل الزبون ومفضلاته عند استخدام المعاينة ومسح بياناتها.
- لا تحفظ بيانات بث تجريبية داخل المشروع أو التقارير.

## اللوحة المستقلة
راجع [دليل التركيب](../selfhost/panel/INSTALL-GUIDE-AR.md) و[مرجع اللوحة](../selfhost/panel/README-AR.md).

- شغّل نسخة واحدة من العملية على ملف JSON واحد؛ لا تفترض أنها تدعم الكتابة المتوازية من عدة عمليات.
- استخدم HTTPS عند إتاحتها عبر الإنترنت، وحدّد المنافذ والجدار الناري وصلاحيات مجلد البيانات.
- خذ نسخة من البيانات قبل الترقية أو الاستعادة، واحفظها خارج المجلد المنشور.
- اختبر الاستعادة على نسخة منفصلة أولًا، ثم تحقق من بيانات الدخول والإعدادات.
- اختبر `/api/public/config` مع التطبيق، وفشل الاتصال والرجوع إلى السحابية، بعد التركيب الفعلي.
- راجع ملف الدخول الأولي والتعامل معه وفق دليل التركيب؛ لا تشارك أسرار الدخول في التقارير.

## التعامل مع رفض البث
ميّز بين نجاح الدخول والقوائم ونجاح تحميل الفيديو. أخطاء 401 و403 و404 ليست اتصالًا صحيًا. رفض الوصول قد يكون مرتبطًا بالحساب أو مزوّد البث أو بيئة الاتصال؛ لا تنسبه إلى حظر عنوان بعينه دون دليل. يلزم اختبار حساب صالح من جهاز مسموح قبل اعتماد التشغيل.

## التسليم
سجّل لكل إصدار: رقم النسخة، اسم الحزمة، بصمة التوقيع العامة فقط، نتيجة الأجهزة، نتيجة البث، نتيجة الحفظ والقراءة، وما لم يُختبر. لا تُعلن اكتمال التشغيل عند نجاح الاختبارات الجزئية فقط.
