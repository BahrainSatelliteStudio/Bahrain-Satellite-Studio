# الطلبات ولوحة التطبيق

## ما تم تنفيذه
- `/workspace`: حساب الزبون وملخص الإدارة وإنشاء حساب زبون للطلبات دون إنشاء تطبيق.
- `/catalog`: اختيار نوع من المشغّل الموجود، تصميم من القوالب السبعة، ثيم وميزات واسم وشعار ووسيلة تواصل. الإدارة تتحكم في إتاحة الأنواع والتصاميم والميزات.
- `/orders` و`/quotes`: طلبات وعروض أسعار منفصلة عن التطبيقات المعتمدة.
- العرض يحفظ نسخة الاختيارات والسعر والعملة والنطاق والمدة والتعديلات وشروط البدء والانتهاء؛ الموافقة تخص النسخة الحالية فقط.
- تجهيز التطبيق إداري بعد قبول العرض واستيفاء شروطه، ويربط التطبيق بصاحب الطلب دون إنشاء حساب جديد أو تغيير توقيع التطبيقات السابقة.
- تنزيل ZIP للوحة مستقلة مخصصة، ملف `delivery.json` يثبت الاختيارات. اللوحة تبقى Node 18 بلا اعتماديات.
- اللوحة السحابية للطلبات الجديدة لا تفتح للزبون قبل التسليم وتعرض الأقسام التشغيلية المختارة؛ الصناعة وتغيير التصميم وهوية التطبيق وفرض التحديث للإدارة.
- تسليم الطلب يتطلب رابط لوحة HTTPS وإصدار APK ناجح وإقرارًا بنتيجة اختبار حقيقي. لا تُنشأ نتائج اختبار أو دفع تلقائية.

## التحقق
نجح 37 اختبارًا: قواعد الطلبات والميزات والقوالب والتفعيل والتوجيه وسجل الفيديو. اختُبر بحساب مصرح: حفظ طلب وإرساله ومراجعته وتسعيره وقبول العرض وتجهيز تطبيق وتنزيل اللوحة والانتقال للاختبار. حذفنا الطلب والتطبيق المؤقتين بعد التحقق. اختُبرت لوحة مستقلة محلية: حفظ التواصل وإعادة قراءته، رفض الهوستات والرسائل غير المختارة وتغيير الهوية.

## المتبقي وحدوده
- اختبار حساب زبون غير مسؤول لم يُجرَ بعد؛ فحص الحساب الإداري ليس بديلًا عنه.
- لم يصدر APK في هذه الجولة، ولا أُجري تثبيت Android/TV أو بث فعلي أو ربط سيرفر زبون منشور.
- إدارة أكواد التفعيل موجودة في اللوحة السحابية. اللوحة المستقلة تدعم بروتوكول التفعيل الخارجي السابق، ولا تنتج بعد إدارة الأكواد الداخلية؛ يجب إدارة هذه الميزة سحابيًا عند اختيارها، وعدم وصف اللوحة المستقلة بأنها تدعم إدارة الأكواد الداخلية.
- تثبيت اللوحة وضبط نطاقها يتطلبان سيرفر الزبون؛ التنزيل لا يعني أن اللوحة منصبة.
- Firebase الخاص بكل تطبيق والتوقيع وبناء APK يستمرون عبر المسار الموجود دون تغيير.
- الاتصال والدفع والتسعير والتصدير الآلي مراحل مستقبلية، وليست ضمن التنفيذ الحالي.
- حساب الزبون للطلبات يُنشأ من الإدارة؛ لا تسجيل عام جديد ولا جدول ملفات شخصية.
