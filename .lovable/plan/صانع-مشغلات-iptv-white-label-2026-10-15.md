# صانع مشغلات IPTV (White-label)

## الفكرة
منصة واحدة: أنت (المسؤول الأعلى) تنشئ زبائن، وكل زبون يحصل على تطبيق أندرويد مستقل باسمه وشعاره، ويتحكم فيه من لوحة خاصة به.

## الأجزاء
1. **لوحة المسؤول (أنت)**
   - إضافة/تعطيل زبائن، وإنشاء حساب دخول لكل زبون.
   - زر "بناء APK" لكل زبون + سجل البناءات ورابط تنزيل الملف.
2. **لوحة الزبون** (يرى تطبيقه فقط)
   - الهوية: الاسم، الشعار، الألوان.
   - السيرفرات/الهوستات: Xtream Codes، روابط M3U، بوابات MAC.
   - رسائل وإعلانات تظهر داخل التطبيق.
   - أرقام الدعم (واتساب/تلغرام) + إجبار تحديث برقم نسخة.
3. **تطبيق المشغل (للمشتركين)**
   - شاشة دخول: Xtream / M3U / MAC.
   - أقسام: قنوات مباشرة، أفلام، مسلسلات، بحث، مفضلة.
   - مشغل فيديو يدعم HLS/TS، يقرأ الهوية والرسائل من لوحة الزبون عند كل فتح.
   - تصميم داكن عصري مناسب للتلفاز والجوال.
4. **بناء APK لكل زبون**
   - عند الضغط على "بناء": GitHub Actions يبني APK باسم الزبون وشعاره ومعرّف حزمة خاص (مثل me.bhsat.<code>) ويرفع الملف للوحة.
   - صفحة "طريقة التثبيت" قابلة للمشاركة لكل زبون مع رابط تنزيل APK.

## مراحل التنفيذ
1. قاعدة البيانات والصلاحيات (مسؤول / زبون) + تخزين الشعارات وملفات APK.
2. لوحة المسؤول ولوحة الزبون.
3. تطبيق المشغل (Xtream + M3U + MAC).
4. نظام البناء التلقائي وصفحة التثبيت.

## تفاصيل تقنية
- جداول: tenants، tenant_members، user_roles، servers، announcements، builds.
- رابط عام /api/public/app/<code> يرجع إعدادات التطبيق.
- MAC Portal وبعض سيرفرات Xtream تحتاج تمرير الطلبات عبر خادمنا (proxy) بسبب قيود المتصفح.
- البناء يحتاج ربط GitHub + مفتاح وصول (token) لتشغيل البناء من اللوحة.
- استبدال اللوحة السابقة بالكامل.
