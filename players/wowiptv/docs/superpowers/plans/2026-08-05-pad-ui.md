# PAD UI 响应式适配 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有单模块项目中为横屏平板（expanded 窗口尺寸）提供自适应 UI，手机布局保持不动。

**Architecture:** 用 `LocalConfiguration.screenWidthDp` 做两档断点（<840dp 走手机布局，≥840dp 走 PAD 布局），零新依赖。每个页面新增 tablet 分支私有 composable，与手机分支互不干扰。数据层零改动；新增纯函数排序工具（可单测）。导航结构：MainScreen 顶部全局栏（logo+搜索）+ 左侧 NavigationRail（设置置底），5 个 tab 的页面在 tablet 下隐藏自带 TopAppBar 避免双栏。

**Tech Stack:** Kotlin 2.1.20, Jetpack Compose (BOM 2024.12.01), Navigation Compose, Hilt

参考 spec：`docs/superpowers/specs/2026-08-05-pad-ui-design.md`

```kotlin
package com.dream.wowiptv.presentation.common

import com.dream.wowiptv.R

enum class SortMode(val labelRes: Int) {
    AZ(R.string.sort_az),
    RECENT(R.string.sort_recent)
}

fun <T> applySort(
    items: List<T>,
    mode: SortMode,
    nameOf: (T) -> String,
    dateOf: (T) -> String?
): List<T> = when (mode) {
    SortMode.AZ -> items.sortedBy { nameOf(it).lowercase() }
    SortMode.RECENT -> items.sortedByDescending { dateOf(it) }
}
```
