# i18n 中文/英文 支持

日期: 2026-07-31
状态: 待确认

## 目标

让应用支持中文、英文双语界面,通过 Android 资源体系 (`values/` + `values-en/`) 迁移全部 UI 文案,并在设置页加入语言切换(跟随系统 / 中文 / English)。

## 背景

- 全 app 约 200 条中文文案硬编码在 24 个 Kotlin 文件(presentation 层为主,少量 data/domain 层错误消息)
- `values/strings.xml` 仅含 `app_name`,无 `values-en/`
- `MainActivity` 继承 `ComponentActivity`,未用 appcompat 的 locale API
- 但 `androidx.appcompat:appcompat:1.7.1` 依赖已在 `build.gradle.kts`,可直接使用 `AppCompatDelegate.setApplicationLocales`

## 方案选型

| 维度 | 选定方案 |
|---|---|
| 运行时资源 | Android 资源体系 `values/`(中文默认)+ `values-en/` |
| 语言切换 | appcompat 1.7 `AppCompatDelegate.setApplicationLocales` |
| 组合层取串 | `stringResource(R.string.x)` |
| 非组合层取串 | `context.getString(R.string.x)` |
| 翻译工作流平台 | 不引入(个人项目,后续需要再接入 Crowdin/Localazy) |

## 架构

### 1. 语言切换基础设施

- 主题: `themes.xml` 的 `Theme.WowIPTV` parent 从 `Theme.MaterialComponents.DayNight.DarkActionBar` 改为 `Theme.AppCompat.DayNight.NoActionBar`(AppCompatActivity 必需 AppCompat 主题;NoActionBar 避免顶部多出 ActionBar)
- `MainActivity`: 继承 `ComponentActivity` → `AppCompatActivity`
- 新增 `res/xml/locale_config.xml`:
  ```xml
  <locale-config xmlns:android="http://schemas.android.com/apk/res/android">
      <locale android:name="zh" />
      <locale android:name="en" />
  </locale-config>
  ```
- `AndroidManifest.xml` application 加 `android:localeConfig="@xml/locale_config"`(Android 13+ 系统"每应用语言"自动同步)
- 语言三态映射:
  - 跟随系统 → `AppCompatDelegate.setApplicationLocales(AppLocales.emptyList())`
  - 中文 → `AppCompatDelegate.setApplicationLocales(AppLocales.forLanguageTags("zh"))`
  - English → `AppCompatDelegate.setApplicationLocales(AppLocales.forLanguageTags("en"))`
- 存储/持久化/ recreate 全由 AppCompatDelegate 内部处理。**不新增 DataStore 键,不手写 attachBaseContext**
- 设置页当前选项读取 `AppCompatDelegate.getApplicationLocales()`:空 = 跟随系统

### 2. 字符串迁移

- 新建 `res/values-en/strings.xml`;`res/values/strings.xml` 扩为全部中文文案(默认)
- 命名规范按前缀分区:`common_*` / `home_*` / `live_*` / `movies_*` / `series_*` / `player_*` / `epg_*` / `settings_*` / `err_*`
- 组合层: `Text(stringResource(R.string.xxx))`
- 带参数串(如 `到期 %s`、`最大连接 %s`、倍速 `%sx`、时间 `%02d:%02d`): `stringResource(R.string.xxx, arg...)`,格式串保留 `%` 占位
- Toast / click 回调 / ViewModel: 通过注入的 `@ApplicationContext Context` 或 `LocalContext.current` 调 `getString`
- 迁移推进顺序(按文件): common 组件 → 设置/主页 → 直播/电影/剧集 → 详情/播放器/EPG → 数据层错误

### 3. 错误消息本地化

- 数据层面向用户的异常消息(`PlayStreamUseCase` 的 `"M3U 源不支持点播/剧集"`、`"No active source selected"`,`M3uRepository` 等)改为类型化异常:
  - `SourceNotSupportedException`(M3U 源不支持点播/剧集)
  - `NoActiveSourceException`(未选择源)
  - 其余同理,按需新增
  - ViewModel catch 类型化异常后 `context.getString(R.string.err_*)` 发出本地化文案
- ViewModel 内 `"加载失败"` / `"加载收藏失败"` / `"暂无数据"` 等: 注入 `@ApplicationContext Context`,用 `context.getString` 发出
- 纯日志类中文(不面向用户显示)不迁移

### 4. 设置页语言选项

- "通用设置" 区新增 `语言` 下拉选择行(复用现有 `PlaybackSpeedRow` 下拉行样式)
- 选项: 跟随系统 / 中文 / English
- 点选 → `AppCompatDelegate.setApplicationLocales(...)` → 立即生效(AppCompatDelegate 自动 recreate),无需手动 Toast

## 数据流

```
SettingsScreen 语言下拉
  → SettingsViewModel.setLanguage(lang)   // 直接调 AppCompatDelegate
  → AppCompatDelegate.setApplicationLocales(locales)
  → Activity recreate + 资源按新 locale 重解析
  → 所有 stringResource/getString 返回新语言
```

## 错误处理

- 迁移遗漏检查: 用 grep 扫描 `presentation/` 下残留中文字符串,确保零遗漏
- 语言切换失败无需特殊处理(appcompat API 幂等,setApplicationLocales 无返回值)

## 边界

- 日期格式化 (`SimpleDateFormat(..., Locale.getDefault())`) 不受强制应用语言影响,保持现状不改
- app 名 `WowIPTV` 不翻译
- 不引入复数/拼写差异处理(当前文案无复数敏感场景)
- M3U 源名、频道名、EPG 数据等用户数据不翻译

## 测试计划(手动)

1. 切换 English → 遍历主页/直播/电影/剧集/设置/详情/播放器/EPG 全 tab,验证无残留中文
2. 空状态、错误状态、Toast 文案验证
3. 切回中文,验证恢复
4. 切"跟随系统",系统语言中文→显示中文;系统语言英文→显示英文
5. Android 13+ 系统设置里出现"每应用语言"且与 app 内选择同步
6. 带参数串(到期时间、倍速、时间码)格式正确
